# MC458
Repositório com resolução de trabalhos da disciplina MC458 na Unicamp

Enunciado: 

Formato de entrada
A primeira linha contém um inteiro n indicando o número de aeronaves (n). As 
linhas seguintes contêm, cada uma, dois inteiros xi e yi indicando as
coordenadas da aeronave i (0 <= i < n)

Formato de saída
Imprima os pares de índices de aeronaves (i, j) que possuem a distância cartesiana mínima, onde i < j (um par por linha)

Entrada:
2
0 0
3 4
Saída:
(0,1)
Existem apenas duas aeronaves e a distância cartesiana entre elas é 5.
